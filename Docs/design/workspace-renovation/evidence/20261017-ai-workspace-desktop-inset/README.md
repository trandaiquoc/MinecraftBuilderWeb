# Create with AI Desktop Inset Review

The desktop Create with AI workspace previously placed its content directly
against the Structure JSON dialog's inner edge, unlike the header, outer tabs,
and footer. The workspace now uses a 12 px inset on all sides to align its
content with those surrounding surfaces.

## Verification and limits

- The desktop capture uses the existing one-block project, Dark theme, and
  Description tab. No prompt text was entered or copied.
- The 390 px and 320 px captures keep all five AI tabs within their buttons;
  the document width matches each viewport.
- The import dialog was closed after review. No AI service was called and no
  project data or saved preferences were changed.
- Full Workspace visual acceptance remains open in the
  [acceptance inventory](../../WORKSPACE-UI-ACCEPTANCE-INVENTORY.md).
