# Desktop Sidebar Composition — 2026-10-17

## Scope

These current Chrome captures compare the default Minecraft Workspace layout
before and after aligning its side panel widths with the approved desktop
composition. The local project is an empty 16 × 16 × 16 structure in English.

## Change

At a 1600 × 1000 browser window, the previous 260 px left and 230 px right
defaults left a 1092 px central viewport and truncated many block labels. The
new 360 px left and 400 px right defaults give the browser and inspector room
to show their content, while preserving a 320 px minimum central viewport.
Existing saved widths remain unchanged; the new values apply to new defaults
and the layout reset action.
