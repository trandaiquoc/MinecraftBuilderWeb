# Block Browser List Composition - 2026-10-17

## Scope

These Chrome captures compare the Block Browser at the approved 360 px left
panel width and check the drawer at a narrow viewport. The browser project is a
temporary empty 16 x 16 x 16 structure in English.

## Change

The previous browser grouped blocks into narrow tiles, which wrapped names and
truncated registry IDs at the approved panel width. Each block now occupies one
80 px virtual row with its preview beside the name and registry ID. Virtual
scrolling and the existing block actions remain in place.
