# Selected Project Card State — 2026-10-17

## Scope

These Chrome 155 captures use a temporary browser profile with one locally
created 16 × 16 × 16 Java 1.21.1 project. The screenshots show the latest board
composition at 1600 × 1000 in all four themes and at 390 × 844 in Dark.

## Finding and change

The selected project card used the bright selected-control token. In Dark this
made the card pale gray against the moonlit board and dark interface. The card
now uses the selected-surface token blended with its normal surface, retaining
the theme accent border and the existing metadata hierarchy.
